\subsection{Accessibility Checklist}
\begin{itemize}
\item Text contrast $\geq 4.5{:}1$; colour is not the only way to convey information
\item All functions usable with the keyboard; visible focus
\item Form fields have labels; error messages explain how to fix the problem
\item Layout works on mobile and desktop (responsive)
\end{itemize}
