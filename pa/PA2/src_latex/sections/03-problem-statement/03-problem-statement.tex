bình nước, thiết bị điện tử,\ldots{} Hiện tại, việc tìm kiếm phụ thuộc
vào các hội nhóm Facebook/ Zalo tự phát, dẫn đến thông tin bị phân tán
trên nhiều nền tảng, bài đăng bị trôi nhanh chóng, thiếu kiểm duyệt
chính danh và khó kết nối nếu vật phẩm bị rơi ngoài phạm vi trường học
của mình.

\item
  \textbf{Operating Environment \& Constraints}
\end{enumerate}

\begin{itemize}
\item
  \textbf{Operating Environment:} Trình duyệt web hiện đại (Google
  Chrome, Mozilla Firefox, Safari) hỗ trợ HTML5/ CSS3/ JavaScript trên
  PC và thiết bị di động (Responsive Web App); máy chủ đám mây (Render/
  Vercel/ Supabase).
\item
  \textbf{Design \& Implementation Constraints:}
\end{itemize}

\begin{itemize}
\item
  \textbf{Tech Stack:} Frontend: React; Backend: Node.js với Express.js;
  Database: Supabase (PostgreSQL).
\item
  \textbf{Process:} Mô hình Waterfall, quản lý mã nguồn bằng Git/GitHub
  tuân thủ quy tắc Conventional Commits và Pull Request review.
\item
  \textbf{Schedule Constraint:} tối đa 3 tuần coding cho các tính năng
  cốt lõi (PA5).
\end{itemize}
